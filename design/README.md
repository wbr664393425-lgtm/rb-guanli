# 日报截图登记 · 简版页面设计

## 设计图

- [员工登记页](employee-mobile.png)：手机 H5，首次选择姓名，以后自动记住；选择、拖拽或粘贴截图后提交。设计图展示已选图、待提交状态；提交后原位显示“已提交”。
- [管理员总览页](admin-today.png)：参照用户提供的紧凑姓名标签样式，一屏显示当天 33 人；未提交人员排在最前，已提交人员显示蓝色对勾，点击姓名可查看截图。

两张图是界面设计稿，图中的日期、提交人数和时间仅用于展示布局，实际页面从记录计算。桌面可拖拽和粘贴图片；微信内以选择相册图片为主要入口，粘贴能力需在目标手机上验证。

## 页面边界

员工和管理员通过同一域名下的两个固定链接进入，例如 `/` 与 `/admin`；域名只需在浏览器首次输入或收藏，不在页面内再次填写。管理员使用单独密码进入总览。每天零点切换当天状态，历史截图和记录保留；两页顶部日期默认今天，点击日期可选过去某天，用于补传或回看，仍使用同一页布局。截图上传成功即计入所选日期，不识别或审核截图内容。
